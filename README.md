📊 Customer Sales Dashboard – Power BI

💡 An interactive Power BI dashboard designed to analyze customer sales performance, identify key trends, and support data-driven business decisions.

🧩 Project Overview

This project presents a Customer Sales Dashboard built using Power BI to visualize and analyze sales data across customers, products, and regions.
It helps businesses track sales KPIs, trends, and customer insights to improve strategy and performance.

🎯 Objective

Analyze overall sales and profit performance.

Identify top customers, products, and sales regions.

Provide an interactive view of KPIs to support decision-making.

Highlight sales trends and patterns over time.

🛠️ Tools & Technologies
Tool	Purpose
🟡 Power BI	Data modeling, visualization, and dashboard creation
🧮 Excel	Data cleaning, preprocessing, and source file
📐 DAX	Custom KPIs and calculated measures for sales and profit

The dataset contains:
